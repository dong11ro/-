# ADR-010: ML 앙상블을 라우터로 두고, 불일치 건만 LLM에 넘긴다

- **상태**: 채택
- **날짜**: 2026-08-31
- **관련**: FR-06~11, NSM, [ADR-005](ADR-005-LLM-교체가능-인터페이스.md), [ADR-006](ADR-006-자각-보존.md), [ADR-008](ADR-008-분류체계-거버넌스.md)

## 맥락

[04 §4](../04_1차설계.md)에서 분류 엔진을 4계층(이력 → 사업자번호 → 키워드 → LLM)으로 설계하고, 이력 매칭 상한이 44.8%라는 실측을 근거로 **"LLM은 필수"** 라고 단정했다.

**그 판단에 빠진 것이 있었다: 규칙과 LLM 사이에 ML 계층이 없다.**

그리고 검증 전략도 비어 있었다 — *"LLM이 분류하고 LLM이 검증하면 무엇이 보장되는가"* 라는 질문에 답이 없었다.

## 먼저 — 검증은 두 층위다

| | 무엇을 검증 | 검증자 |
|---|---|---|
| **개발 시** | 이 분류기가 얼마나 정확한가 | **정답셋 22,047건** |
| **운영 시** | 이 한 건이 맞나 | **결정론적 제약 + 사람** |

**LLM 자기검증 계층은 넣지 않는다.** 같은 모델의 자기 검증은 같은 실수를 반복하며 아무것도 보장하지 않는다.
LLM의 역할은 *"정답 보장"* 이 아니라 **"사람이 봐야 할 양을 줄이는 것"** 이다. 최종 검증자는 사람이며([ADR-006](ADR-006-자각-보존.md) P-1), 그 앞에 환각이 불가능한 결정론적 제약을 둔다:

```
① 출력이 활성 분류 목록에 실제로 존재하는가
② 수입 거래에 지출 분류가 붙지 않았는가 (kind 정합)
③ 금액 부호와 type이 일치하는가
④ 취소 거래에 분류가 붙지 않았는가 (FR-34)
   → 하나라도 실패하면 '미분류'로 강등
```

## 결정 — 파이프라인

```
        입력 (상세명·가맹점·금액·날짜)
                 ↓
 ① 이력 완전일치        커버 45%  정확 97%   무료·즉시
 ② 사업자번호 정확매칭   일부      정확 최상   무료·즉시
                 ↓  (미해결 건)
 ③ ★ ML 앙상블 — 3개 모델 병렬 (수 ms)
        ┌──────────┼──────────┐
     TF-IDF     FastText    임베딩
     (문자열)   (서브워드)   (의미)
        └──────────┼──────────┘
                 ↓ 합의 판정
      3/3 일치 ──→ 자동확정 (고액 제외)
      2/3 일치 ──→ ??? (홀드아웃으로 결정)
      불일치   ──→ ④
                 ↓
 ④ LLM 폴백      불일치 건 + 새 분류 대응
                 ↓
 ⑤ 사람          임계 미달 · 고액 · 제약 위반
```

## 근거

### ML 계층을 넣는 이유

| 조건 | 우리 상황 |
|---|---|
| 학습 데이터 | 22,047건 / 8,521 고유 상세명 — 텍스트 분류에 충분 |
| 문제 유형 | 짧은 한국어 텍스트 → 132개 클래스. 전형적 분류 문제 |
| 비용 | 학습·추론 사실상 0 |
| **신뢰도 품질** | ★ softmax 확률이 **LLM의 자기보고 신뢰도보다 훨씬 잘 보정(calibrated)** 된다 |

마지막 항목이 결정적이다. 자동확정 정책(FR-10)이 *신뢰도 × 금액*으로 분기하는데, LLM이 *"확신도 90%"* 라고 말하는 것은 근거가 약하다. **ML의 확률값은 실제 정확도와 대응시킬 수 있다.**

### 앙상블 합의를 라우터로 쓰는 이유

ML 추론이 사실상 무료이므로 3개를 돌려도 부담이 없고, **서로 다른 표현을 쓰는 모델들이 독립적으로 같은 답에 도달했다는 사실은 단일 모델의 신뢰도보다 강한 증거**다 (query by committee / disagreement-based deferral).

**다양성 확보가 핵심**이다. 비슷한 모델 3개는 의미가 없다:

| 모델 | 보는 것 | 강점 |
|---|---|---|
| TF-IDF(문자 n-gram) + 로지스틱회귀 | 표면 문자열 | 정확·부분 일치 |
| FastText | 서브워드 | 오타·표기 변형 (`스타박스`, `STARBUCKS`) |
| 한국어 임베딩 + 분류 헤드 | 의미 | `메가커피` → 카페 |

**세 모델이 서로 다른 이유로 틀리기 때문에** 합의가 의미를 갖는다.

### 상관된 오류 — 한계를 명시한다

같은 데이터로 학습하면 같은 실수를 한다. 전원 일치인데 전원 틀릴 수 있다.
그리고 그 상한은 이미 측정되어 있다:

```
상세명 → 분류 일관성 = 96.9%   (8,521개 중 339개가 분류 불일치)
```

**이는 라벨 자체의 노이즈이므로 어떤 모델도 넘지 못한다. 정확도 상한 ≈ 97%.**
목표 85%는 그 안에 들어오지만, **100%는 불가능**하다 — 남은 3%는 모델 문제가 아니라 12년간 쌓인 판단 흔들림이다.

## 미정 — 데이터로 결정한다

`2/3 일치`의 처리만 열어둔다. 홀드아웃으로 아래 표를 채우면 근거 있게 정해진다:

| 합의 상태 | 정확도 | 비율 | 처리 |
|---|---|---|---|
| 3/3 | ? | ? | 자동확정 |
| **2/3** | ? | ? | **← 결정 지점** |
| 불일치 | ? | ? | LLM |

selective prediction의 **risk-coverage tradeoff**이며, NSM(커버리지 85%)과 가드레일(오분류율 5%)이 이 곡선 위의 한 점이다.

**최종 확정 규칙은 3축이 된다**: `자동확정 = f(합의도, 신뢰도, 금액)`

## [ADR-005](ADR-005-LLM-교체가능-인터페이스.md)의 판정을 수정한다

> ~~"LLM은 선택이 아니라 목표 달성의 필수 조건"~~ → **"ML 실험 후 재판정"**

44.8%는 **완전일치**만 잰 숫자다. ML은 부분 일치·유사도·문맥을 쓰므로 훨씬 높을 수 있다.
**ML만으로 85%가 나오면 LLM은 폴백으로만 남는다.**

다만 LLM이 완전히 불필요해지지는 않는다 — **새로 추가된 분류는 ML이 학습하지 못했으므로 LLM만 맞힐 수 있다** ([ADR-008](ADR-008-분류체계-거버넌스.md) 파생).

## 실험 계획

```
프로토콜   train: 2018~2024   test: 2025~2026 (시간 분할 — 랜덤 분할은 미래 정보 누수)
지표      커버리지 / 정확도 / 고액 정확도 / LLM 호출률

실험 1  이력 완전일치만              → 44.8%  ✅ 측정 완료
실험 2  + TF-IDF 로지스틱회귀        → ?
실험 3  + FastText                  → ?
실험 4  + 한국어 임베딩              → ?
실험 5  3-모델 앙상블 합의 분석       → 합의도별 정확도 표
실험 6  + LLM (불일치 건만)          → 최종 커버리지·정확도
실험 7  임계 튜닝 (risk-coverage)    → FR-10 임계값 확정
```

**실험 2~4에서 85%가 나오면 실험 6은 불필요하다.**

## 결과

- ✅ LLM 호출을 "어려운 샘플"에만 집중 → 비용·지연 최소화
- ✅ 보정된 신뢰도 확보 → FR-10 임계 정책의 근거가 생김
- ✅ 정확도 상한(97%)을 명시해 비현실적 목표를 방지
- ✅ 검증 책임이 명확 — 결정론적 제약 + 사람. LLM 자기검증 없음
- ⚠️ 모델 3개의 학습·버전관리 부담 (경량 모델이라 감당 가능)
- ⚠️ **다양성이 없으면 앙상블이 무의미**하다. 유사 모델 3개는 안 된다

## 기각한 대안

| 대안 | 기각 사유 |
|---|---|
| **파싱 결과를 전부 LLM에** | 이력으로 45%가 무료로 해결되는데 낭비. 비용·지연 과다 |
| **ML 결과를 LLM이 검증** | 같은 실수를 반복. 아무것도 보장하지 않으면서 비용만 2배 |
| **단일 ML 모델 + 신뢰도 임계** | 동작하지만 단일 softmax는 과신 경향. 앙상블 합의가 더 잘 보정됨 |
| **LLM 없이 ML만** | 새 분류를 맞힐 수 없다 (학습 데이터 부재). 폴백으로 남긴다 |
