# v2 재설계 — 14단계 진행 현황

> [AI 바이브코딩 개발프로세스 v4](../AI_바이브코딩_개발프로세스_v4.md)를 따라 **기획부터 다시** 밟는다.
> 목적: 공부. v1.0.0 코드는 유지하되 "정답"이 아니라 **비교 대상**으로 둔다.
> 설계 결론이 코드와 크게 달라지면 그때 유지/수정/재작성을 결정한다 (리스크 R-5).

## 원칙

- **Plan First, Code with AI, Verify Always** + Evidence Before Approval
- 각 Step은 대화로 도출 → 확정된 것만 문서화
- 결론뿐 아니라 **기각된 선택지와 그 근거**를 남긴다 (틀린 가설 포함)
